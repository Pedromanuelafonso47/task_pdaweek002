# agrotech

Skill do Claude Code que transforma a descrição de uma lavra em Angola (província, cultura, hectares, água,
energia, orçamento em Kz) em sugestões de projetos IoT agrícolas do catálogo AGROGENIUS, com razões, lista de
materiais e preços de referência, sem inventar dados.

Para usar noutro projeto, copia esta pasta para `.claude/skills/` desse projeto e reinicia o Claude Code; a
skill dispara sozinha quando alguém descreve uma lavra e pergunta que tecnologia instalar. Os caminhos do
`SKILL.md` apontam para o catálogo e o motor do AGROGENIUS, por isso fora deste repositório tens de os adaptar.
